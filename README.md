# StudyPilot AI 📚

> An AI-powered personal study assistant for college students — built with FastAPI, Streamlit, SQLite, and your choice of LLM.

---

## Features

| Feature | Description |
|---|---|
| 🧠 AI Study Planner | Personalised day-by-day plan generated by LLM |
| 📊 Dashboard | Progress overview with Plotly charts |
| 🗓️ My Schedule | Session list with mark-complete functionality |
| 🧩 AI Quiz | MCQ generation + scoring + weak-area detection |
| 💬 AI Tutor | Context-aware doubt answering (4 explanation modes) |
| 📄 My Notes | PDF upload + Q&A + summarisation (PyMuPDF) |
| 📈 Progress | Daily/weekly charts, quiz trends, subject breakdown |

---

## Tech Stack

- **Frontend:** Streamlit + Plotly
- **Backend:** FastAPI + Uvicorn
- **Database:** SQLite + SQLAlchemy 2
- **AI:** OpenAI-compatible API (OpenAI, Groq, Together AI, etc.)
- **PDF:** PyMuPDF (fitz)
- **Validation:** Pydantic v2

## Quick Start

### 1. Clone and set up environment

```bash
git clone <your-repo>
cd StudyPilot-AI
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Configure environment variables

```bash
cp .env.example .env
# Edit .env and add your LLM API key
```

**.env example:**
```
LLM_API_KEY=your_api_key_here
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_MODEL=llama-3.1-8b-instant
BACKEND_URL=http://localhost:8000
```

**Supported LLM providers:**
- [OpenAI](https://platform.openai.com) — `gpt-4o-mini`, `gpt-4o`
- [Groq](https://console.groq.com) — `llama-3.1-8b-instant` (fast, free tier)
- [Together AI](https://api.together.xyz) — various open models

### 3. Start the backend

```bash
# From the StudyPilot-AI directory:
uvicorn backend.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`  
Swagger docs: `http://localhost:8000/docs`

### 4. Start the frontend

In a **new terminal**:

```bash
streamlit run frontend/app.py
```

Open `http://localhost:8501` in your browser.

## First Steps in the App

1. Click **New Profile** in the sidebar
2. Enter your name, subjects, exam date, and weak topics
3. Go to **Study Planner** and click **Generate AI Study Plan**
4. Visit **Dashboard** to see your progress overview
5. Use **My Schedule** to mark sessions complete
6. Try **AI Quiz** to test your knowledge
7. Use **AI Tutor** to ask doubts
8. Upload notes in **My Notes** to get AI-powered Q&A

## API Reference

| Method | Endpoint | Description |
|---|---|---|
| POST | `/students` | Create student profile |
| GET | `/students` | List all students |
| GET | `/dashboard/{id}` | Dashboard data |
| POST | `/study-plan/generate` | Generate AI study plan |
| GET | `/study-plan/{id}` | Get all sessions |
| POST | `/study-plan/complete-session` | Mark session complete |
| POST | `/quiz/generate` | Generate MCQ quiz |
| POST | `/quiz/submit` | Submit + score quiz |
| GET | `/quiz/history/{id}` | Quiz history |
| POST | `/tutor/ask` | Ask AI tutor |
| POST | `/notes/upload` | Upload PDF |
| POST | `/notes/ask` | Ask question about PDF |
| POST | `/notes/summarize/{id}` | Summarise PDF |
| GET | `/progress/{id}` | Progress data |

Full interactive docs: `http://localhost:8000/docs`

## Deployment

### Render (Backend)

1. Connect your GitHub repo to [Render](https://render.com)
2. Create a **Web Service**:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
3. Add environment variables in Render dashboard

### Streamlit Cloud (Frontend)

1. Push to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Set **Main file path:** `frontend/app.py`
4. Add `BACKEND_URL` (your Render URL) in Streamlit secrets

## Security Notes

- API keys are never hardcoded — always use `.env`
- `.env` is in `.gitignore` and never committed
- PDF uploads are validated for type and size
- All inputs are validated with Pydantic v2
- Error messages are user-friendly (no technical tracebacks exposed)
